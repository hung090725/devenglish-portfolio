# Github Release Draft

**Tag**: v0.9.0-beta
**Title**: EnglishPath AI 0.9.0-beta

## Nội dung (Release notes)

```markdown
# 🚀 EnglishPath AI v0.9.0-beta

Bản cập nhật tập trung vào môi trường kiểm thử QA nội bộ và khóa học B1!

## 🌟 Tính năng chính
* Tích hợp lộ trình 56 ngày học (từ A0 đến B1).
* Hệ thống Sao lưu & Khôi phục tiến độ học tập 100% offline qua Clipboard.
* Hỗ trợ QA Mode để dễ dàng theo dõi thông số kỹ thuật của app.

## ⚠️ Cảnh báo Beta
Đây là phiên bản Beta dùng để kiểm thử nội bộ. 
- Tính năng Text-To-Speech và Microphone có thể hoạt động khác nhau tùy dòng máy.
- Có thể gặp lỗi. Mong bạn thông cảm và báo lỗi lại cho team nhé!

## 📥 Tải xuống và Cài đặt
1. Tải file `app-release.apk` (hoặc `app-debug.apk`) trong mục **Assets** bên dưới.
2. Mở file để cài đặt. Nếu có cảnh báo Play Protect, chọn "Chi tiết thêm" > "Vẫn cài đặt".
3. Tham khảo chi tiết tại `docs/no_play_release/TESTER_INSTALL_APK_GUIDE.md`.

## 🐛 Báo lỗi
Vui lòng xuất file **Diagnostics JSON** trong màn hình Cá nhân và gửi kèm mô tả lỗi về cho team.
```

**Assets đính kèm**:
- `app-release.apk` (nếu đã ký)
- `app-debug.apk` (nếu chỉ test nội bộ nhanh)
*(Tuyệt đối không đính kèm file .jks hoặc file sao lưu cá nhân)*

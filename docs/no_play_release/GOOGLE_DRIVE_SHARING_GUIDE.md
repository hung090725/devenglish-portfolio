# Hướng dẫn chia sẻ APK qua Google Drive

Nếu file APK quá lớn để gửi qua Zalo/Telegram, hoặc bạn muốn quản lý file tốt hơn, hãy dùng Google Drive.

1. Truy cập vào tài khoản Google Drive của bạn.
2. Tạo một thư mục (Ví dụ: `EnglishPath_AI_Beta`).
3. Upload file `app-release.apk` (hoặc `app-debug.apk`) vào thư mục này.
4. Click chuột phải vào file APK > Chọn **Chia sẻ (Share)**.
5. Ở mục **Quyền truy cập chung (General access)**, đổi từ "Hạn chế (Restricted)" thành **"Bất kỳ ai có liên kết (Anyone with the link)"**.
6. Chọn vai trò là **"Người xem (Viewer)"**.
7. Bấm **Sao chép đường liên kết (Copy link)** và gửi cho tester.

*Lưu ý: Thỉnh thoảng Drive có thể cảnh báo file không quét được virus vì dung lượng lớn. Bạn chỉ cần nhắc tester bấm "Vẫn tải xuống" là được.*

# Hướng Dẫn Khôi Phục Dữ Liệu (Restore Backup)

1. Mở App EnglishPath AI.
2. Tại màn hình Profile / Settings, chọn "Khôi phục dữ liệu".
3. Chọn file `EnglishPath_Backup.json` từ trình duyệt file của máy.
4. App sẽ yêu cầu xác nhận ghi đè. Nhấn OK.
5. App tự động tải lại màn hình với tiến trình học cũ.

*Ghi chú: Nếu có lỗi "File sao lưu không hợp lệ", tức là định dạng file đã bị hỏng hoặc bạn chọn nhầm file không phải do app tạo ra.*

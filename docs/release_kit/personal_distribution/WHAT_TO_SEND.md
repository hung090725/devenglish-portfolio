# WHAT TO SEND

Khi chia sẻ ứng dụng EnglishPath AI cho bạn bè hoặc người dùng thử nghiệm, bạn **CHỈ NÊN GỬI** các thành phần sau:

1. **File cài đặt chính thức:** `app-release.apk` (Phải là bản Signed - Đã ký bằng Keystore).
   - *(Trường hợp ngoại lệ)*: Nếu chỉ cần nhờ một bạn Tester IT test nhanh lỗi màn hình, có thể gửi tạm `app-debug.apk`. Nhưng bản này chạy chậm hơn.
2. **Release Notes:** Thông tin phiên bản (Có gì mới, sửa lỗi gì).
3. **Install Guide:** Hướng dẫn cài đặt APK thủ công cho những người chưa từng cài app ngoài Play Store.
4. **Bug Report Template:** File mẫu báo lỗi để người dùng điền nếu gặp sự cố.

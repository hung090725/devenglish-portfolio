# WHAT NOT TO SEND

Để bảo vệ sự an toàn của hệ thống và quyền riêng tư, bạn **TUYỆT ĐỐI KHÔNG ĐƯỢC GỬI** các file hoặc thông tin sau cho người khác:

1. **Không gửi file `.jks` (Java KeyStore):** Đây là chữ ký điện tử duy nhất định danh nhà phát triển. Mất file này coi như mất quyền sở hữu app.
2. **Không gửi file `signing.properties`:** Chứa đường dẫn và alias bí mật.
3. **Không gửi mật khẩu (Password):** Mật khẩu Keystore hay mật khẩu bí mật nào khác.
4. **Không gửi file Backup cá nhân (`.json`):** Tránh rò rỉ dữ liệu học tập cá nhân của bạn.
5. **Không gửi Diagnostics Report cá nhân:** Trừ khi bạn đang làm việc với Developer của dự án để bắt lỗi hệ thống.
6. **Không gửi Source Code:** Không zip thư mục `app` hay toàn bộ project cho người dùng thường, họ chỉ cần file APK.

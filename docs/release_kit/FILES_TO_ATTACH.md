# FILES TO ATTACH (PERSONAL RELEASE KIT)

Khi gửi Release Kit này cho bạn bè hoặc người dùng thử nghiệm, vui lòng **CHỈ GỬI** các file sau:

* `app-release.apk` (Dành cho người dùng cài đặt bình thường).
* `app-debug.apk` (Nếu dùng test nội bộ, cần xem Log/Diagnostics sâu).
* `app-release.aab` (Để dành sau này nếu muốn up lên Play Store - không cần gửi cho người dùng).

**CẢNH BÁO: KHÔNG BAO GIỜ ĐÍNH KÈM CÁC FILE SAU**
* Tuyệt đối không đính kèm `keystore`
* Tuyệt đối không đính kèm file `.jks`
* Tuyệt đối không đính kèm file backup JSON cá nhân của bạn (tránh rò rỉ dữ liệu).
* Tuyệt đối không đính kèm mật khẩu.

# DANH SÁCH KIỂM TRA CHẤT LƯỢNG SỬ DỤNG (PERSONAL USE CHECKLIST)

Bảng kiểm tra nhanh này giúp bạn xác nhận ứng dụng chạy ổn định trên thiết bị mới trước khi chính thức đầu tư thời gian học tập.

- [ ] 1. Cài app thành công không báo lỗi.
- [ ] 2. Mở app mượt mà, không crash.
- [ ] 3. Chọn level hoạt động trơn tru.
- [ ] 4. Học bài đầu tiên (giao diện bài học tải đủ nội dung).
- [ ] 5. Test tính năng đọc từ vựng (TTS phát âm rõ ràng).
- [ ] 6. Test micro (Hệ thống ghi nhận âm thanh khi luyện nói).
- [ ] 7. Làm trọn vẹn 1 Quiz mà không bị lỗi đơ máy.
- [ ] 8. Chức năng ôn từ vựng (Review) hiển thị thẻ chính xác.
- [ ] 9. Vào phần Backup/Restore và bấm **Export backup** thành công.
- [ ] 10. (Thử nghiệm) Gỡ hoàn toàn app khỏi máy.
- [ ] 11. Cài lại file APK.
- [ ] 12. Dùng tính năng **Restore backup** bằng file vừa export.
- [ ] 13. Kiểm tra lại Progress (tiến trình học vẫn còn nguyên).
- [ ] 14. Sao chép và cất giấu file Backup JSON ở nơi lưu trữ an toàn (Google Drive/Máy tính).

# 🚀 EnglishPath AI v0.9.0-beta

Cập nhật Sprint 11 - Tập trung vào Khóa B1 và tính năng Sao lưu cục bộ.

* **Khóa học B1 (Giao tiếp)**:
  * Thêm 14 ngày học mới (Days 43 - 56).
  * 200+ từ vựng tập trung vào giao tiếp và công việc.
  * 18 điểm ngữ pháp trung cấp.
  * 16 bài hội thoại tình huống thực tế.
  * 70 câu hỏi trắc nghiệm ôn tập.

* **Sao lưu & Khôi phục dữ liệu (Local Backup/Restore)**:
  * Không cần tạo tài khoản hay kết nối mạng.
  * Cho phép sao lưu toàn bộ tiến độ học tập ra văn bản JSON (Clipboard).
  * Khôi phục nhanh chóng qua Clipboard khi đổi máy hoặc cài lại ứng dụng.
  * Tránh mất dữ liệu học tập quan trọng.

## 🛠 Cải tiến & Sửa lỗi
* Điều chỉnh UI màn hình Cá nhân để hiển thị tiến độ B1.
* Tối ưu hóa cơ chế seed data để ngăn chặn trùng lặp.
* Cải thiện hiệu suất load dữ liệu trong màn hình Lộ trình học.

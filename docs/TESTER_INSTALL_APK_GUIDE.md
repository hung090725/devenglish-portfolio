# Hướng dẫn Cài đặt Beta App qua file APK

Cảm ơn bạn đã tham gia thử nghiệm app **EnglishPath AI**!
Dưới đây là hướng dẫn cài đặt file APK trên điện thoại Android của bạn.

---

## 1. Tải file APK
- Bạn sẽ nhận được file `app-release.apk` (hoặc `app-debug.apk`) qua link Google Drive, Zalo hoặc GitHub do team gửi.
- Hãy bấm vào link để tải file về máy.
- Mở thông báo tải xong, hoặc vào ứng dụng **Quản lý file** (My Files) > thư mục **Tải về** (Downloads).

## 2. Cho phép cài đặt từ nguồn không rõ (Unknown Sources)
Do app đang ở giai đoạn Beta chưa đưa lên CH Play, điện thoại có thể cảnh báo khi cài đặt.

1. Bấm vào file APK vừa tải để cài đặt.
2. Nếu hiện thông báo "Vì lý do bảo mật, điện thoại không được phép cài đặt ứng dụng không rõ nguồn gốc", chọn **Cài đặt** (Settings).
3. Bật tùy chọn **Cho phép từ nguồn này** (Allow from this source).
4. Nhấn phím Quay lại (Back) và tiếp tục chọn **Cài đặt** (Install).

## 3. Quét bảo mật Play Protect
Nếu Google Play Protect hiện cảnh báo "Blocked by Play Protect" (báo ứng dụng lạ vì chưa có trên Play Store):
1. Bấm **Chi tiết thêm** (More details)
2. Chọn **Vẫn cài đặt** (Install anyway)

## 4. Kiểm tra app
- Mở app **EnglishPath AI**.
- App sẽ yêu cầu cấp quyền **Ghi âm** (để luyện nói). Vui lòng chọn **Cho phép khi dùng ứng dụng** (Allow while using app).
- Nếu đã có dữ liệu học tập từ bản cũ, bạn có thể dùng tính năng **Sao lưu / Khôi phục** trong mục Cá nhân (Profile).

## 5. Gửi phản hồi
- Trong mục Cá nhân, bấm nút **Gửi phản hồi Beta**.
- Hoặc liên hệ trực tiếp với chúng tôi qua Zalo/Telegram.

Chúc bạn có trải nghiệm học tập thú vị với EnglishPath AI!
